# go2w_om6dof_agent

ROS 2 dashboard for OM6DOF on the Jetson AGX. Go2W remains on the Jetson NX;
the AGX dashboard works without a connection to the NX.

See the build, run, and systemd installation guide in
[`application/application_web_monitor/README.md`](application/application_web_monitor/README.md).
